a basic 4 function calculator app

## what do i do.
my features concise of 
* adding, subtraction, multiplication and division
* handle parenthesis and decimals
* not immediate math but type up expression then hit equals

## how it work
it basically has a grid layout of buttons that use signal depending on if they are symbol they'll do on_symbol_pressed and if they are a number vice versa, then i will check what symbol and run whatever code so like if its an + it will check if theres any other symbol before the plus to change it to a plus and then add itself to the preview and the expression which is later parsed and checked for errors before showing it to the user in the actual display label.
